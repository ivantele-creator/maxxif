# Maxxi Internet Fibra — site

Site estático responsivo criado com HTML, CSS e JavaScript.

## Arquivos
- index.html
- style.css
- script.js
- assets/maxxi-fibra.png

## Antes de publicar
1. Trocar os preços dos planos pelos valores reais.
2. Trocar o número do WhatsApp em `script.js`.
3. Configurar o link da Área do Cliente.
4. Ajustar e-mail, cidades atendidas e dados legais.
5. Integrar o formulário de cobertura ao sistema/CRM.
